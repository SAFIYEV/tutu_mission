# Сценарий демонстрации для жюри

## Демо за 3 минуты

**0:00–0:25 — проблема.** Пользователь знает, куда и когда ему нужно успеть, но не должен вручную сравнивать десятки билетов.

**0:25–0:55 — постановка задачи.** Ввести:

> Завтра к 18:00 мне нужно быть в Санкт-Петербурге. Я в Москве. Бюджет до 15 000 ₽, без самолёта, приехать минимум за два часа и вернуться следующим утром.

Показать распознанные ограничения до запуска.

**0:55–1:30 — живой процесс.** Обратить внимание, что числа на экране приходят из текущего trace: найденные предложения, комбинации и этапы фильтрации.

**1:30–2:10 — результат.** Показать один план, актуальные ссылки Туту, объяснение выбора и независимый verifier. Подчеркнуть: LLM не может выставить статус «проверено».

**2:10–2:40 — невозможная миссия.** Уменьшить бюджет или запретить доступный транспорт. Показать минимальное изменение и автоматический повторный поиск.

**2:40–3:00 — технология.** Открыть архитектурную схему: Bedrock понимает язык, Tutu MCP даёт предложения, чистый TypeScript решает и проверяет.

## Карта критериев

| Критерий | Что увидит жюри |
|---|---|
| Понимание задачи · 10 | Инверсия поиска: пользователь задаёт цель, продукт берёт ответственность за решение |
| Функциональность · 15 | Транспорт + отели + валюты + solver + verifier + impossible mission + Plan B |
| UX/UI · 20 | Один главный маршрут, прозрачный solving trace, мобильная адаптация, явные error states |
| Презентация · 5 | 3-минутный сценарий и готовая презентация в репозитории |
| Документация · 10 | README, architecture, deploy guide, env template, Mermaid-схемы |
| Инновационность · 10 | Claude Sonnet 4.6 через Bedrock в роли parser, официальный MCP и доказуемое решение |
| Стабильность · 10 | retry, timeout, partial results, cache, abort, error taxonomy, 70 тестов |
| Архитектура · 10 | ports/adapters, чистый домен, composition root, проверяемые dependency rules |
| Код · 10 | TypeScript strict, Zod boundaries, CI quality gate, детерминированные unit tests |

## Запасные запросы

- «12 сентября к 10:00 быть в Казани из Москвы, до 18 000 ₽, не больше одной пересадки, обратно через 3 дня».
- «Через 5 дней к 14:00 быть в Сочи из Санкт-Петербурга, найди отель на две ночи, общий бюджет 60 000 ₽».
- «Завтра к 9:00 быть в Екатеринбурге из Баку, бюджет 2 000 манат, самолёт разрешён».

Перед публичным демо проверить текущую доступность направлений в Tutu MCP. Для внешнего outage интерфейс имеет отдельное честное состояние и кнопку повтора.
